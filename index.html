Network Reconfiguration

PT BPR Madani Sejahtera Abadi

Konfigurasi ulang menggunakan MikroTik setelah konfigurasi sebelumnya mengalami reset/error. Jaringan internal digabung ke dalam satu segmen agar pencatatan dapat dilakukan langsung melalui jaringan lokal, sementara jaringan Guest dan Server tetap dipisahkan.

Akses juga diamankan dengan firewall untuk membatasi akses langsung dari jaringan Guest maupun Internet menuju server database internal.
